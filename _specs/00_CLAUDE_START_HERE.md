# frontend-starter-kit — стартовый промпт для Claude

## Роль Claude

Ты выступаешь как Senior Frontend Engineer / Frontend Architect. Твоя задача — поэтапно спроектировать и затем реализовать frontend-проект `frontend-starter-kit`.

Важно: не писать весь код сразу одним полотном. Работай итеративно, строго по этапам из `02_IMPLEMENTATION_ROADMAP.md`.

## Цель проекта

Создать базовый frontend-шаблон для хакатонов и быстрых прототипов.

Проект должен быть одновременно:

1. готовым скелетом приложения;
2. UI-kit на базе shadcn/ui и кастомных компонентов;
3. showcase-песочницей интерфейсных сценариев;
4. демонстрацией правильной архитектуры Feature-Sliced Design;
5. базой, из которой команда сможет быстро брать таблицы, формы, графики, панели, авторизацию, роли, тему и PWA.

## Название проекта

`frontend-starter-kit`

## Язык интерфейса

Русский.

Все пользовательские тексты, подписи, ошибки, состояния, меню и кнопки должны быть на русском языке.

## Визуальный стиль

Нейтральный современный SaaS.

Требования:

- аккуратный;
- спокойный;
- не слишком яркий;
- без ощущения “нейросеточного” шаблона;
- без перегруза градиентами;
- без кричащих цветов;
- хорошо работает в light и dark theme;
- выглядит как нормальная внутренняя бизнес-система / SaaS-панель.

## Важное ограничение

Не превращай проект в один продуктовый кейс.

Это не CRM, не таск-трекер и не админка как конечный продукт.

Это именно `frontend-starter-kit`, где сущности вроде пользователей, проектов, заявок и аналитики нужны только для демонстрации UI-паттернов.

## Принцип работы

Работай по этапам.

На каждом этапе:

1. кратко объясни, что будет сделано;
2. перечисли файлы, которые будут созданы/изменены;
3. затем дай код;
4. после кода дай команды для проверки;
5. дай критерии готовности этапа;
6. не переходи к следующему этапу, пока текущий не завершён логически.
