# Быстрый старт

## Требования

- Node.js >= 18
- npm >= 9

## Установка и запуск

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Сборка для production
npm run build

# Предпросмотр собранного
npm run preview

# Storybook
npm run storybook

# Линтинг
npm run lint
```

## Страницы приложения

| Путь | Описание |
|------|----------|
| `/login` | Вход в систему |
| `/dashboard` | Главная панель с KPI и графиками |
| `/tables` | DataTable с CRUD-операциями |
| `/charts` | Четыре типа графиков (Line/Bar/Area/Donut) |
| `/forms` | Примеры форм (Dialog / DetailsPanel / страница) |
| `/panels` | DetailsPanel: просмотр и редактирование |
| `/ui-kit` | Витрина всех UI-компонентов |
| `/settings` | Тема, профиль, уведомления |
