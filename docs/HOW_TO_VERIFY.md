# Как проверить работоспособность проекта

## 1. Запуск

```bash
npm install   # только один раз, если node_modules ещё нет
npm run dev
```

Откроется сервер на http://localhost:5173

---

## 2. Чек-лист проверки по страницам

### /login — Вход

- [ ] Страница открывается без ошибок
- [ ] Есть поля email и пароль
- [ ] Есть 3 кнопки быстрого входа: Администратор / Менеджер / Пользователь
- [ ] Нажать «Администратор» → страница перебрасывает на /dashboard
- [ ] Заголовок в sidebar показывает имя пользователя

---

### /dashboard — Дашборд

- [ ] Видны 4 карточки KPI с числами и трендом ± %
- [ ] Видны 3 графика: Area, Donut, Line
- [ ] Переключение периода (7д / 30д / 90д) перезагружает данные
- [ ] Список «Последние пользователи» справа
- [ ] Кнопка «Новый пользователь» — ведёт на /tables

---

### /tables — Таблицы

- [ ] Таблица со строками пользователей загружается
- [ ] Поиск в поле — фильтрует строки в реальном времени
- [ ] Клик на заголовок колонки — сортировка asc/desc
- [ ] Пагинация (кнопки «Назад/Вперёд» если строк > 10)
- [ ] Checkbox выбора строк — появляется панель «Выбрано: N»
- [ ] Кнопка «Удалить выбранные» → диалог подтверждения → строки удаляются
- [ ] Три точки в строке → меню «Редактировать / Удалить»
- [ ] У роли `user` — кнопки Удалить/Добавить не видны

---

### /charts — Графики

- [ ] 6 графиков на странице (Line, Bar, Area, Donut, Bar stacked, Area stacked)
- [ ] Переключение периода (7д / 30д / 90д) в верхнем правом углу
- [ ] Hover на точку/столбец — показывает tooltip с данными
- [ ] Легенда кликабельна (скрывает/показывает серии)

---

### /forms — Формы

- [ ] Кнопка «Открыть диалог» → открывает модальное окно с формой
- [ ] Попытка отправить пустую форму → красные ошибки валидации под полями
- [ ] Заполнить все поля → нажать «Создать» → toast «Пользователь создан»
- [ ] Кнопка «Открыть панель с формой» → открывается боковая панель

---

### /panels — Панели

- [ ] Страница открывается, есть список элементов
- [ ] Клик на элемент → открывается DetailsPanel справа
- [ ] Кнопка Pin (иконка булавки) — закрепляет панель (не закрывается кликом вне)
- [ ] Кнопки ← → в панели — навигация между элементами
- [ ] Режим редактирования — кнопка «Редактировать» → поля становятся активными
- [ ] Попытка закрыть с несохранёнными изменениями → диалог «Данные не сохранены»

---

### /ui-kit — UI Kit

- [ ] Страница открывается, 4 вкладки: Атомы / Молекулы / Обратная связь / Оверлеи
- [ ] Вкладка «Обратная связь» → кнопка «Success» → появляется зелёный toast
- [ ] Кнопка «Удалить запись» → открывается ConfirmDialog
- [ ] Вкладка «Оверлеи» → «Открыть диалог» → открывается Dialog

---

### /settings — Настройки

- [ ] Страница открывается, три секции: Профиль / Уведомления / Внешний вид
- [ ] Изменить имя → кнопка «Сохранить» становится активной
- [ ] Нажать «Сохранить» → toast «Профиль обновлён»
- [ ] Переключить тему «Тёмная» → интерфейс становится тёмным
- [ ] Переключить обратно «Системная» → возврат к системной теме

---

### Тёмная тема (глобально)

- [ ] Header → иконка темы (солнце/луна) → выбрать «Тёмная»
- [ ] Все страницы переключаются в тёмный вид
- [ ] Графики адаптируются (цвета из CSS-переменных)

---

### Роли и доступ

- [ ] Выйти (меню пользователя → «Выйти»)
- [ ] Войти как «Гость» через кнопку быстрого входа
- [ ] Убедиться, что в sidebar нет пунктов Таблицы/Формы
- [ ] Попытка зайти напрямую на /tables → редирект на /access-denied

---

## 3. Storybook

```bash
npm run storybook
```

Открыть http://localhost:6006 — должна открыться витрина компонентов.

- [ ] В левом меню видны разделы: UI/Button, UI/Badge, UI/DataTable и др.
- [ ] Выбрать Button → видны варианты Default, Sizes, Loading и т.д.
- [ ] В панели Background (toolbar вверху) выбрать «dark» → компоненты переключаются в тёмный вид

---

## 4. Production сборка

```bash
npm run build
npm run preview
```

Открыть http://localhost:4173 — приложение работает как в dev, но из собранных файлов.
