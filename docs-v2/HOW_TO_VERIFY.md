# Как проверить работоспособность проекта

## 1. Запуск

```bash
npm install   # только первый раз
npm run dev
```

Открыть http://localhost:5173 — должна появиться страница входа.

---

## 2. Проверка по страницам

### /login — Вход в систему

**Быстрая проверка:**
- [ ] Страница открывается, нет ошибок в консоли браузера (F12 → Console)
- [ ] Есть поля email и пароль с плейсхолдерами
- [ ] Есть 3 кнопки быстрого входа: «Администратор» / «Менеджер» / «Пользователь»

**Функциональная проверка:**
- [ ] Нажать «Войти как Администратор» → переход на /dashboard
- [ ] В sidebar виден аватар и имя «Admin User»
- [ ] Попытка войти с неверным паролем (email правильный, пароль «wrong») → красная ошибка под формой
- [ ] Заполнить форму вручную (admin@example.com / demo) → успешный вход

---

### /dashboard — Дашборд

**Визуальная проверка:**
- [ ] 4 карточки KPI в верхней строке с числами
- [ ] Под каждой карточкой — трендовый показатель (+/-%)
- [ ] Карточки имеют иконки (Users, FolderOpen, FileText, CheckSquare)

**Графики:**
- [ ] Area-chart (занимает ~2/3 ширины) — виден
- [ ] Donut-chart (занимает ~1/3 ширины) — виден с легендой
- [ ] Line-chart внизу — виден

**Интерактивность:**
- [ ] Переключатель периода (7д / 30д / 90д) — клик меняет данные в графиках
- [ ] Ховер на точку графика — появляется tooltip с данными
- [ ] Список «Последние пользователи» в правом блоке

### /tables — Таблица пользователей

**Данные:**
- [ ] Таблица со строками пользователей отображается (не пустая, не ошибка)
- [ ] Видны колонки: Пользователь, Email, Команда, Роль, Статус, Дата

**Поиск:**
- [ ] В поле поиска ввести «Ivan» → таблица фильтруется
- [ ] Нажать × в поле поиска → данные возвращаются полностью

**Сортировка:**
- [ ] Клик на «Имя» → сортировка по алфавиту A-Z
- [ ] Повторный клик → Z-A
- [ ] Третий клик → возврат к исходному порядку

**Пагинация:**
- [ ] Если записей больше 10 — видны кнопки «Назад/Вперёд»
- [ ] Кнопки отображают правильный счётчик «Страница 1 из N»

**Выбор строк:**
- [ ] Кликнуть checkbox у строки → появляется синяя галочка
- [ ] Появляется панель сверху «Выбрано: 1»
- [ ] Кликнуть checkbox в шапке → выбираются все строки текущей страницы

**CRUD-операции:**
- [ ] Кнопка «Добавить пользователя» → открывается диалог с формой
- [ ] Заполнить форму, нажать «Создать» → toast «Пользователь создан», запись добавлена в таблицу
- [ ] Три точки у строки → меню «Удалить» → диалог подтверждения → запись удалена
- [ ] Кнопка «Удалить выбранные» → диалог → записи удалены

**Права доступа:**
- [ ] Выйти, войти как «user@example.com» (роль user) → кнопка «Добавить» отсутствует

### /panels — Детальная панель

**Список:**
- [ ] Страница открывается, видны карточки/строки элементов

**Открытие панели:**
- [ ] Клик на элемент → открывается DetailsPanel справа
- [ ] Панель содержит данные выбранного элемента
- [ ] Клик за пределами панели → панель закрывается

**Pin (закрепление):**
- [ ] Кнопка булавки (📌) → панель остаётся открытой при клике вне
- [ ] Повторный клик на булавку → режим pin снят

**Навигация:**
- [ ] Кнопки ← → в заголовке панели → переключение между элементами
- [ ] На первом элементе кнопка ← недоступна, на последнем — →

**Редактирование:**
- [ ] Кнопка «Редактировать» → поля становятся активными для ввода
- [ ] Изменить значение → нажать «Сохранить» → toast, данные обновились

## 5. Что делать при ошибках

### Красные ошибки в консоли браузера

Нажать F12 → Console. Записать текст ошибки. Чаще всего это:
- `Cannot find module` — что-то с импортом. Проверить путь и имя файла.
- `is not defined` — использование переменной до объявления. Проверить импорты.
- `TypeError: undefined is not an object` — обращение к полю null/undefined объекта. Добавить `?.` или проверку.

### Страница не открывается (белый экран)

F12 → Console — смотреть ошибку. Обычно что-то упало при рендере.

```bash
npm run typecheck

```
